# 🌟 우리 아이들 앱

`index.html`을 더블클릭하면 크롬이나 엣지에서 바로 열려요. 설치할 것은 없어요.

| 앱 | 위치 | 하는 일 |
|---|---|---|
| 💰 용돈기입장 | `allowance/index.html` | 받은 돈, 쓴 돈 기록, 저금 목표, 월별 통계, 정기 용돈 버튼 |
| ✍️ 필사 달력 | `pilsa/index.html` | 매일 문장 따라 쓰기(공책/화면/타자), 스티커 달력, 연속 기록, 부모님 확인 도장 |

## 아이별 문장 난이도 (태어난 해 기준, 자동)
- 초1~3 → 우리 속담
- 초4~6 → 사자성어
- 중학생 이상 → 고전·명언

## 알아 두기
- 기록은 **이 컴퓨터의 브라우저 안에** 저장돼요. 다른 기기와는 공유되지 않아요.
- 처음 화면 아래쪽 **백업 파일 내려받기**로 가끔 백업해 두세요.
- 문장 목록은 `pilsa/sentences.js`에서 고칠 수 있어요.

## 📱 휴대폰에서 쓰기
이 폴더는 휴대폰 앱처럼 설치할 수 있게 준비되어 있어요(PWA). 휴대폰에서 열려면 먼저 인터넷 주소(https)에 올려야 해요.

1. 폴더를 무료 호스팅(GitHub Pages, Netlify 등)에 올려요.
2. 휴대폰에서 그 주소를 열어요.
   - 안드로이드(크롬): 메뉴 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
   - 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 **우리앱** 아이콘으로 열면 인터넷이 없어도 열려요.

> 앱 파일을 고친 뒤에는 `sw.js` 맨 위의 `VERSION`을 `v2`, `v3`…처럼 올려야 휴대폰에 새 버전이 들어가요.
> 기록은 휴대폰마다 따로 저장돼요. 아이가 각자 자기 폰에서 쓰면 자기 기록만 남아요.

## 폴더 구조
```
index.html          처음 화면 (앱 고르기, 아이 정보, 백업)
shared/common.css   공통 디자인
shared/common.js    아이 프로필, 저장, 백업 같은 공통 기능
allowance/          용돈기입장
pilsa/              필사 달력 (+ sentences.js 문장 모음)
```
