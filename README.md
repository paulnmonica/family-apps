# 🌟 우리 아이들 앱

초등학생 두 아이를 위한 **따로따로 설치하는 앱 두 개**예요. 설치할 것은 없고, 크롬이나 엣지에서 바로 열려요.

| 앱 | 위치 | 하는 일 |
|---|---|---|
| 💰 용돈기입장 | `allowance/` | 받은 돈, 쓴 돈 기록, 저금 목표, 월별 통계, 정기 용돈 버튼 |
| ✍️ 필사 달력 | `pilsa/` | 매일 문장 따라 쓰기(공책/화면/타자), 내가 읽은 책 기록, 스티커 달력, 연속 기록, 부모님 확인 도장, 가족 문장 제안 |

맨 위의 `index.html`은 두 앱으로 가는 **설치 안내 페이지**일 뿐, 앱이 아니에요.

## 누가 쓰나요
- **필사 달력**: 아빠, 엄마, 첫째, 둘째, 셋째 — 온 가족
- **용돈기입장**: 둘째, 셋째
- 식구 정보는 한 곳(`family.kids`)에 있고, 앱마다 쓰는 사람만 보여 줘요(`shared/common.js`의 `APP_MEMBERS`).
  이름·아이콘·태어난 해·색깔은 **⚙️ 설정 → 가족 정보(아이 정보)**에서 바꿔요.
- **💌 가족 문장**: 누구나 좋은 글을 제안할 수 있고, 제안한 문장은 온 가족의 매일 문장에 섞여 나와요.
  사람마다 `pilsa.words-<id>`에 따로 저장돼요. 자기 문장만 뺄 수 있고, 아빠·엄마(관리자) 기기에서는 모두 뺄 수 있어요.
- **기기 설정**: 아빠·엄마를 고르면 자동으로 관리자 기기가 되어 모두의 기록을 보고 가족 정보를 고칠 수 있어요. 아이를 고르면 그 아이 기록만 보여요.

## 문장 난이도 (태어난 해 기준, 자동)
- 초1~3 → 우리 속담
- 초4~6 → 사자성어
- 중학생 이상(어른 포함) → 고전·명언

## 알아 두기
- 기록은 **이 기기의 브라우저 안에** 저장돼요.
- 각 앱의 **⚙️ 설정 → 백업 · 복원**으로 가끔 백업해 두세요. 백업 파일은 앱마다 따로 만들어져요.
- 문장 목록은 `pilsa/sentences.js`에서 고칠 수 있어요.

## 📱 휴대폰에 설치하기
휴대폰에 설치하려면 먼저 인터넷 주소(https)에 올려야 해요(GitHub Pages 등).

1. 휴대폰에서 설치할 앱 주소를 열어요. 예) `…/allowance/` 또는 `…/pilsa/`
   - 안드로이드(크롬): 메뉴 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
   - 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
2. 홈 화면에 **용돈기입장**, **필사달력** 아이콘이 따로 생겨요. 인터넷이 없어도 열려요.

> 앱 파일을 고친 뒤에는 그 앱 폴더의 `sw.js` 맨 위 `VERSION`을 `v2`, `v3`…처럼 올려야 휴대폰에 새 버전이 들어가요.
> 아이폰은 홈 화면 앱마다 저장 공간이 따로라서, 두 앱을 모두 설치했다면 **앱마다 한 번씩** 기기 설정을 해 주세요.

## ☁️ 구글 시트 동기화
- 기록은 구글 시트 **"우리 아이들 앱 기록"**에도 함께 저장돼요. `요약 / 용돈 / 필사 / 가족 문장` 탭은 보기용 표예요.
- 각 앱을 처음 열면 **⚙️ 설정 → 📱 이 기기 설정**에서 누가 쓰는 기기인지 고르고 가족 확인 코드를 넣어요.
  - 용돈기입장은 설정 탭, 필사 달력은 오른쪽 위 ⚙️ 버튼에 있어요.
- 가족 확인 코드는 Apps Script **프로젝트 설정 → 스크립트 속성 `FAMILY_CODE`**에만 있어요. 코드 파일이나 저장소에는 넣지 마세요.
- Apps Script 코드는 `apps-script/Code.gs`에 있어요. 고친 뒤에는 Apps Script에서 **배포 → 배포 관리 → ✏️ → 새 버전**으로 다시 배포해요.
- 시트를 직접 고친 내용은 앱에 반영되지 않아요. 고칠 때는 앱에서 고쳐 주세요.

## 폴더 구조
```
index.html            설치 안내 페이지 (두 앱으로 가는 링크)
shared/common.css     공통 디자인
shared/common.js      아이 프로필, 저장, 백업, 동기화, 설정 화면
shared/sw-core.js     오프라인 저장 (두 앱의 sw.js가 불러 씀)
allowance/            💰 용돈기입장 앱 (index.html, manifest, sw.js, icons/)
pilsa/                ✍️ 필사 달력 앱 (index.html, sentences.js, manifest, sw.js, icons/)
```
